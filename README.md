# Link in Bio — Roberto Mota

Página pessoal e links de Roberto Mota ([rbto20.com](https://rbto20.com)), construída com HTML e CSS puros e hospedada na Vercel.

## 📁 Estrutura do Projeto

- `index.html`: Página principal com os links.
- `privacidade.html`: Página com informações de privacidade e hospedagem.
- `style.css`: Estilização e carregamento da fonte local JetBrains Mono.
- `assets/`: Imagens, tags e arquivos de fonte.
- `vercel.json`: Configurações de cabeçalhos e cache para deploy na Vercel.

## 🚀 Como Executar Localmente

Você pode rodar qualquer servidor HTTP simples na raiz do projeto:

```bash
# Com Python
python -m http.server 3000

# Ou com Node / npx
npx serve .
```

Acesse em `http://localhost:3000`.

## 🌐 Deploy

Configurado para deploy automático na Vercel conectado a este repositório.
